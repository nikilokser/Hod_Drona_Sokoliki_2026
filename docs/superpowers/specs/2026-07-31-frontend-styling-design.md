# Дизайн: визуальное оформление веб-морды

Дата: 2026-07-31

## Контекст и цель

Функционально веб-морда (доска, режимы, часы, лента переговоров, привязка роботов,
согласование хода ИИ, Stockfish-анализ) уже реализована по спекам
`2026-07-30-web-board-design.md`, `2026-07-30-match-clock-design.md`,
`2026-07-30-chat-feed-design.md`, `2026-07-30-stockfish-analysis-design.md`,
`2026-07-31-ai-move-negotiation-design.md`. Эта спека — только про визуальное оформление
и расположение уже существующих панелей: цветовая палитра, типографика, раскладка страницы,
стиль компонентов. Логика доски, drag-and-drop, API и WebSocket не меняются.

Опорная точка — нынешний `web/frontend/` (единая тёмная палитра, панели стопкой друг под
другом: тулбар → часы → анализ → привязка роботов → предложение хода ИИ → доска+чат).

## Направление

Чистый минимализм в духе lichess/chess.com: доска — визуальный якорь, панели вокруг —
аккуратные и малозаметные, минимум «робо»-тематики. Лого команды «Соколики» — слева сверху
в шапке, пока заглушкой (эмодзи + текст), заменяется одним элементом позже без переделки
вёрстки. Акцентный цвет по всему интерфейсу — соколиный янтарно-оранжевый.

## 1. Структура страницы

```
┌──────────────────────────────────────────────────────┐
│ 🦅 Соколики   [Режим ▾] [Цвет ▾]   ● Gateway ● WS  ☀/☾ │  ← header, всегда виден
├──────────────────────────────────────────────────────┤
│  Ход: Белые (наш ход)      ⏱ 04:32        🕐 1:58:12   │  ← полоса часов, всегда видна
│              [Старт] [Ход сделан] [Пауза] [Завершить]  │
├───────┬──────────────────────────────┬─────────────────┤
│ eval- │                              │  Лента          │
│ bar   │           ДОСКА (SVG)        │  переговоров    │  ← регламент: всегда на экране
│ (║)   │                              │  [+ системные]  │
│       │                              │  [Отправить ▸] │
├───────┴──────────────────────────────┴─────────────────┤
│ [Ход ИИ]  [Привязка роботов]  [Анализ]                  │  ← вкладки, редко нужны
│  … содержимое активной вкладки …                        │
└──────────────────────────────────────────────────────┘
```

- **Header** — одна компактная строка, не растёт по высоте: лого, режим и цвет как
  выпадающие «чипы» (сейчас — отдельные подписанные `<select>` в тулбаре, визуально
  переоформляются в компактные чипы без подписи-лейбла рядом), статусы Gateway/WS как
  цветные пилюли (точка-индикатор + текст вместо голого цветного текста), переключатель
  темы (☀/☾) справа.
- **Полоса часов** — остаётся отдельным блоком сразу под header, самый крупный текст на
  странице (часы — то, на что смотрят чаще всего), кнопки управления матчем в той же строке
  или сразу под ней при переносе на узких экранах.
- **Доска + eval-bar + чат** — одна строка, три колонки. Eval-bar — вертикальная полоска
  впритык к левому краю доски (как на lichess), а не отдельная горизонтальная панель над
  всем остальным, как сейчас. Показывается только когда включён Stockfish-анализ
  (`stockfish_enabled`); резервировать под неё место, когда она скрыта, не нужно —
  доска занимает освободившуюся ширину. Полоса лежит рядом с доской, а не «плавает»
  отдельно, чтобы визуально сразу читалась как аннотация к позиции, а не как отдельный
  виджет.

  Ориентация полосы следует за переворотом доски: при `boardFlipped` (наш цвет — чёрные)
  доля белых на полосе отображается сверху, а не снизу, — так сторона на полосе всегда
  совпадает с тем, где эта сторона физически стоит на доске.
- **Вкладки снизу** — заменяют нынешние два `<details>` («Привязка роботов»,
  «Предложение хода (ИИ)»): «Ход ИИ» (кнопка «Предложить ход» + лог согласования),
  «Привязка роботов» (список привязок + кнопка «Сбросить поле» — опасное действие,
  переезжает сюда из header), «Анализ» (тумблер Stockfish + текстовая рекомендация; сама
  полоска eval-bar рендерится у доски, а не внутри вкладки). Активная вкладка выделяется
  акцентной подложкой/подчёркиванием.
- **Адаптивность** — на экранах уже ~900px чат уходит под доску (колонка вместо строки),
  вкладки становятся горизонтально прокручиваемыми. Структура та же, просто в один
  столбец — отдельной «презентационной» вёрстки для проектора не делаем, вместо этого
  крупный текст часов и полей масштабируется через `clamp()`.

## 2. Цветовая палитра

Обе темы — тёмная (доработка нынешней) и светлая (новая, тёплый нейтральный фон вместо
чистого белого), с переключателем. Токены как CSS custom properties, переключение через
`data-theme="light"|"dark"` на `<html>`; значение хранится в `localStorage`, по умолчанию —
`prefers-color-scheme`.

| Токен | Тёмная | Светлая | Назначение |
|---|---|---|---|
| `--bg` | `#0d0f13` | `#f7f5f2` | фон страницы |
| `--surface` | `#171a21` | `#ffffff` | панели, карточки |
| `--surface-2` | `#20242e` | `#f0eee9` | инпуты, hover-состояния |
| `--border` | `#2a2f3b` | `#e2e4ea` | границы панелей/инпутов |
| `--text` | `#e8e9ec` | `#1c2029` | основной текст |
| `--text-muted` | `#9aa1b0` | `#5b6472` | подписи, метаданные, timestamp'ы |
| `--accent` | `#e8963e` | `#c96a12` | соколиный янтарь: основные кнопки, активная вкладка, обводка своих фигур |
| `--accent-soft` | `#3a2c18` | `#fdf1de` | фон чипов/бейджей на акценте |
| `--success` | `#6bd08f` | `#1f9d55` | «онлайн», «ход вовремя» |
| `--danger` | `#e05656` | `#d1373d` | ошибки, просрочка, опасные кнопки |

Доска и её рамка **не зависят от темы** — коричнево-бежевые клетки (`--light-square`,
`--dark-square`) и тёмная деревянная рамка остаются одинаковыми в обеих темах: это имитация
реальной физической доски, а не элемент UI-палитры, и переключение темы не должно менять
то, что судьи видят как «шахматную доску».

## 3. Типографика и отступы

- Шрифт — системный стек (`-apple-system, "Segoe UI", sans-serif`, как сейчас), без
  подключения внешних веб-шрифтов: на выездных соревнованиях сеть ненадёжна, рисковать
  сломанной типографикой из-за недогруженного файла ради небольшой эстетической разницы
  не стоит.
- Табличные цифры (`font-variant-numeric: tabular-nums`) — для часов и eval-bar, уже
  используется, сохраняется, чтобы цифры не «прыгали» по ширине при обновлении.
- Крупный текст часов (`.clock-value`) масштабируется через `clamp()` вместо
  фиксированного `1.3rem` — читаемо и вплотную на ноутбуке, и издалека на проекторе, без
  отдельной ветки вёрстки.
- Единый шаг отступов 4px (4/8/12/16/20/24 — как фактически используется сейчас),
  скругления 8–10px на панелях, 6px на кнопках и инпутах — без изменений по факту, просто
  формализуется как явный стандарт вместо разрозненных значений.

## 4. Компоненты

- **Кнопки**: основное действие в контексте («Старт матча», «Ход сделан», «Предложить ход
  ИИ») — заливка `--accent`; второстепенные — поверхность панели с рамкой (как сейчас, но
  на новых токенах); опасные («Сбросить поле», «Завершить матч») — `--danger`, без
  изменений в логике подтверждения (`confirm-overlay` остаётся как есть).
- **Статус-пилюли** (Gateway/WS-соединение, онлайн роботов в привязках, текущий режим):
  точка-индикатор + текст на скруглённой подложке вместо голого цветного текста
  (`.status`), чтобы состояние читалось на проекторе даже при плохой цветопередаче.
- **Вкладки**: переиспользуют существующий паттерн `<details>`/`summary` там, где не важна
  единственность открытой секции, но панели «Ход ИИ» / «Привязка роботов» / «Анализ»
  становятся настоящими вкладками (одна видима одновременно) — реализуются на чистом
  JS-переключении `hidden`, без сборки/фреймворка.
- **Лента переговоров** (`.chat-panel`): пузырьки (входящие/исходящие/системные) остаются
  как есть по структуре, только цвета переезжают на новые токены. Уже реализованный
  фильтр-тумблер «+ системные события» (`chat-show-system-toggle`, скрывающий
  `status`/`availability`/`error`-события по умолчанию, оставляя только `command`/`answer`)
  остаётся в шапке панели, оформляется тем же компактным `.toggle-label`, что и тумблер
  Stockfish.
- **Лого**: слева в header — эмодзи-заглушка 🦅 + текст «СОКОЛИКИ»; при появлении
  настоящего лого меняется один `<img>`/`<span>`, разметка вокруг не трогается.

## 5. Что не входит в эту итерацию

- Сам SVG-рендер доски, drag-and-drop логика, состав API и WebSocket-протокол — не
  меняются, это чисто визуальный и структурный (HTML-разметка) слой поверх уже
  реализованной логики.
- Судейский алгоритм, реальная ArUco-локализация, Kill Switch — вне скоупа, как и во всех
  предыдущих спеках (см. `CLAUDE.md`).

## Тестирование

Чисто визуальные изменения — без изменений в бэкенд-логике и без новых юнит-тестов.
Проверка вручную в браузере после реализации: обе темы (переключатель), обе ширины экрана
(десктоп и <900px), все три вкладки, отображение/скрытие eval-bar при включении/выключении
Stockfish, читаемость статус-пилюль и цветов в обеих темах.

## Расположение в репозитории

Изменения только в `web/frontend/` — `index.html` (переразметка header/вкладок/лого/
переключателя темы), `styles.css` (токены, обе темы, стили новых компонентов), `board.js`
(минимальная добавка: переключение вкладок, переключение и персист темы через
`localStorage`, перерасчёт ориентации eval-bar при `boardFlipped`). `web/backend/` не
затрагивается.

## Открытые вопросы (не блокируют реализацию)

- Настоящее лого команды «Соколики» — используется заглушка (эмодзи + текст), заменяется
  позже одним элементом.
