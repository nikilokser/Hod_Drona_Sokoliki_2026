# Веб-морда — доска (v1)

Дизайн: `docs/superpowers/specs/2026-07-30-web-board-design.md`.

## Запуск

```
cd web/backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --reload --port 8000
```

Открыть `http://127.0.0.1:8000`.

## Тесты

```
cd web/backend
.venv/bin/pytest
```

## Переменные окружения

- `GATEWAY_BASE_URL` — адрес Gateway организаторов (`sverk_ai_communication_server`),
  используется только в режиме «Ручные ходы». По умолчанию `http://127.0.0.1:8080`.
- `STOCKFISH_PATH` — путь к бинарнику Stockfish (см. ниже). По умолчанию `stockfish`
  (ищется в `PATH`).

## Stockfish (анализ позиции)

Бинарник **не входит в репозиторий** — ставится отдельно:

```
brew install stockfish   # macOS
```

Панель «Анализ позиции» показывает рекомендацию Stockfish по текущей позиции.
**Регламент запрещает использование шахматных движков для выбора хода во время
зачётного матча** — переключатель по умолчанию выключен, включение требует
подтверждения с явным предупреждением. Это инструмент для анализа/тренировки,
не для реального матча. Если бинарник не найден при старте бэкенда, панель
просто отвечает ошибкой «Stockfish не установлен» вместо падения сервера.

## Привязка робот → фигура

Задаётся в `web/backend/config/bindings.json`, ключ — роль фигуры (`king`, `queen`,
`bishop_1`/`bishop_2`, `knight_1`/`knight_2`, `rook_1`/`rook_2`, `pawn_1`..`pawn_8`),
значение — `robot_id`. `_1` — экземпляр со стороны вертикали `a`, `_2` — со стороны `h`;
пешки нумеруются по вертикали от `a` до `h`. Привязка статична на весь матч и назначается
фигурам нашего цвета при построении стартовой позиции; при дальнейших ходах `robot_id`
переезжает вместе с фигурой.

## Режимы поля

- **Наблюдение (`view`)** — только просмотр, перемещения запрещены.
- **Коррекция позиций (`correct`)** — свободный drag-and-drop любых фигур, без обращений
  к роботам. Для синхронизации UI с реальным состоянием поля.
- **Ручные ходы (`manual`)** — тот же drag-and-drop, но для своих (привязанных) фигур
  дополнительно отправляет команду `лети в клетку {to}` через Gateway на соответствующий
  `robot_id`.

Формат клетки на доске (`state.py`) согласован с design-doc `move_validator`
(`docs/superpowers/specs/2026-07-30-move-validator-design.md`), валидатор ходов сюда пока
не подключён — это отдельная задача.
